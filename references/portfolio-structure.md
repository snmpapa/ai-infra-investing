# Portfolio Structure

Use this file when the user mixes different kinds of exposure that should not be managed the same way.

The goal is to prevent:

- tactical high-beta names from becoming disguised core holdings
- symbolic narrative positions from consuming core capital
- short-term trading decisions from contaminating the long-term portfolio

## Three-Sleeve Model

Prefer this structure when the user holds both AI compounders and tactical AI trades.

### 1. Main Portfolio

Purpose:
- long-term AI exposure
- layered portfolio construction
- deliberate risk budgeting

Typical contents:
- `GOOG`
- `META`
- `NVDA`
- `TSM`
- `AMD`
- `MU`
- `DRAM`
- `CRCL`
- `HOOD`
- `GLD`

Rules:
- this is the main capital pool
- use stack layers, portfolio buckets, and add/reduce triggers
- do not let theme positions crowd out core holdings
- do not chase tactical momentum here

### 2. Tactical High-Beta Sleeve

Purpose:
- exploit familiar volatility
- trade price zones in levered AI-exposed names
- capture upside without promoting these names into core holdings

Typical contents:
- `IREN`
- `GLXY`
- sometimes `CRWV`
- sometimes `NBIS`

Rules:
- define these as trades, not base holdings
- total sleeve size should usually stay in a controlled range
- partial profit-taking is normal
- realized gains should preferentially flow back to the main portfolio or cash

### 3. Strategic Narrative Sleeve

Purpose:
- preserve participation in rare, long-duration narratives
- maintain symbolic or strategic exposure without forcing a large position

Typical contents:
- `TSLA`

Rules:
- treat this as participation rights, not proof of core conviction
- keep size small
- do not automatically upgrade this sleeve into a satellite holding
- only enlarge if operating execution clearly strengthens the thesis

## How To Talk About The Sleeves

When the user mixes names from different sleeves, explicitly label them:

- `main portfolio`
- `tactical high-beta sleeve`
- `strategic narrative sleeve`

This avoids false comparisons such as:
- comparing `GOOG` and `IREN` as if they serve the same role
- sizing `TSLA` like a clean AI infrastructure holding
- treating a profitable tactical trade as evidence that it deserves core status

## Suggested Controls

Use plain rules such as:

- tactical high-beta names have a separate total cap
- narrative participation names have a small fixed cap
- core holdings are funded first
- tactical profits can be harvested faster than core positions

## Key Principle

Different roles require different rules.

A stock can be:
- a good trade
- a useful narrative placeholder
- a poor core holding

Those are not contradictions.
