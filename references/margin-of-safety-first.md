# Margin of Safety First

Use this file when the user explicitly prioritizes downside protection over speed of deployment.

This is the default mode for investors who say things like:

- "I need safety margin."
- "I am not in a hurry to build the position."
- "I prefer to wait."
- "I would rather miss part of the move than buy without protection."
- "Sell puts are for cheaper entry, not for forcing a position."

## Core Principle

Do not optimize for:
- immediate target completion
- cosmetic portfolio symmetry
- fear of missing out

Optimize for:
- favorable entry asymmetry
- psychological comfort after entry
- willingness to hold through small adverse movement
- patient accumulation only when risk-reward is clearly favorable

## Practical Meaning

In this mode:

- a target holding can remain underweight for a long time
- a desired stock does not need to be bought immediately
- waiting is an active decision, not indecision
- sell puts are a price-discipline tool, not a position-forcing tool

## Three-Tier Buy Zone Model

Use three zones instead of one:

### 1. Aggressive Watch Zone

Meaning:
- price is improving
- worth watching more closely
- not yet a comfortable size-up area

Action:
- monitor
- do not rush

### 2. Standard Entry Zone

Meaning:
- acceptable for small initial entry
- better than chasing
- still not ideal if the user is highly conservative

Action:
- small entry only
- or use options for more patient entry

### 3. Conservative Margin Zone

Meaning:
- this is the preferred zone for a safety-margin-first investor
- risk-reward is more favorable
- the user is less likely to regret entry if the stock drifts lower first

Action:
- this is the main deployment zone
- ideal area for patient scaling or conservative put selling

## Language To Use

Prefer phrases like:

- `do not chase`
- `wait for a better asymmetry`
- `acceptable only for small entry`
- `preferred conservative zone`
- `safety margin is not sufficient yet`
- `underweight is acceptable`

Avoid language that pressures the user into action just because the stock is part of the target portfolio.

## Important Distinctions

- `good company` does not equal `good entry`
- `target holding` does not equal `buy now`
- `missing exposure` does not equal `urgent action`
- `waiting` does not equal `doing nothing`

## Sell Put Guidance

In this mode, puts should be used mainly when:

- the stock is a real target holding
- the user wants a lower effective entry
- the strike sits closer to the standard or conservative zone

Do not use puts just to manufacture action when the user would rather wait.

## Output Preference

When this mode applies, frame conclusions like this:

1. `Belongs in portfolio or not`
2. `Do not chase / acceptable now / wait`
3. `Aggressive watch zone`
4. `Standard entry zone`
5. `Conservative margin zone`
6. `Possible sell-put strikes`
7. `Why patience is justified`

## Key Principle

The portfolio should be strategically clear.
The entries should still be conservative.
